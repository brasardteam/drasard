# Drasard Demo Build Plan

We are developing the restaurant demos one by one.

## Order
1. Nova Café — first
2. Aurelia
3. North Table
4. Ember

## Nova Café target
A complete, polished multi-page café demo demonstrating:
- Home
- Menu with categories and filtering
- Product/item detail interactions
- Cart drawer with quantity controls
- Demo checkout flow (no real payment)
- Reservation flow
- Story/About page
- Visit/Contact page
- Responsive mobile navigation
- Distinct café visual identity
- Clear portfolio/demo presentation without false client claims

All demo functionality should be self-contained and should not break the existing Drasard agency site, contact form, language switcher, pricing, or navigation.

After Nova Café is complete and reviewed, continue to Aurelia.
